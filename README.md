# MarkItDown Open

一个跨平台的桌面应用程序，用于将各种文件格式转换为 Markdown。

## 功能特点

- 支持多种文件格式转换
- 简洁直观的用户界面
- 快速高效的转换速度
- 原生桌面体验

## 技术栈

- **前端**: React + TypeScript + Vite
- **后端**: Rust (Tauri) + Python
- **样式**: Tailwind CSS
- **状态管理**: Zustand

## 开发

### 前置要求

- Node.js 18+
- Python 3.11+
- Rust 1.77+

### 安装依赖

```bash
npm install
```

### 开发模式

```bash
npm run tauri dev
```

### 构建

```bash
npm run tauri build
```
