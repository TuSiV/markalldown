# MarkAllDown 2.1.1

Reviewed redaction exports now preserve original filenames by default, including individual Markdown files and entries inside ZIP archives. Filename/folder anonymization remains an explicit optional setting, accessible in both the redaction review and export panels. Selecting it uses sequential document names and flat folders; conflicting naming and structure controls are disabled.

Makes recovery file selection prominent with high-contrast MD/JSON picker buttons, selected filename feedback, larger action targets and clearer primary/secondary actions.

Retains version-2 encrypted batch recovery packs, independent per-file recovery, legacy recovery support, and the optional local encrypted recovery library from 2.1.0.

Includes Windows NSIS/MSI and macOS Apple Silicon/Intel installers. macOS apps are ad-hoc signed and integrity-checked, without Apple Developer ID signing or notarization; first launch may require Privacy & Security > Open Anyway.
